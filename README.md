# broforce-lite
a demake of Broforce game for handhelds

This was made primarily for a Miyoo Mini+
The goal was to have something fun like Broforce, when I don't have access to my computer. One player only.
If you don't know what Broforce is, well I strongly encourage you to have a look for this gem. In 2 words, that's a game about the good ol' time of 'merican movies like Rambo.

First release is quite complete, but of course don't hesitate reporting a bug or providing general feedback.
